# Wubber email templates

Paste these into Supabase → Authentication → Emails → Templates.

| Supabase template | Subject | Body (Source tab) |
|---|---|---|
| Confirm sign up | `Conferma la tua email · Confirm your Wubber email` | `confirm-signup.html` |
| Reset password | `Reimposta la password · Reset your Wubber password` | `reset-password.html` |

Each email is in Italian if the person signed up with the site in Italian, otherwise English.
